# OrkiCAD branding

## Official logo

The primary logo is [`logo_OrkiCAD-AI.png`](../logo_OrkiCAD-AI.png), stored in the repository root and displayed in the README.

## Usage

- Keep the original proportions and sufficient clear space.
- Use the official file for project documentation, landing pages and repository identity.
- Do not stretch, distort or replace the wordmark with an unrelated typeface.
- Future variants (dark background, standalone app icon, SVG vector master) should be reviewed and versioned as separate assets.

## Asset status

- Primary PNG: published.
- SVG master, favicon, desktop app icon and dark variant: planned, not yet published.

## Third-party rights

Branding files are project-specific assets. Their inclusion in this repository does not grant rights to unrelated third-party marks or CAD/AI model logos.

## Product naming convention

- **Official product name:** OrkiCAD (without the AI suffix).
- **Tagline:** Design. Refine. Make.
- **Description:** Open-source parametric CAD, powered by AI.
- The original asset filename `logo_OrkiCAD-AI.png` is preserved until an approved rebranded asset replaces it; do not rename or modify the graphic without checking its contents.
- Internal package names and import paths such as `orkicad_core` remain unchanged for backward compatibility.
- Preferred repository name: `OrkiCAD` (GitHub rename must be performed in repository Settings; links are not live until then).
