# Contributing

Thanks for your interest in OrkiCAD AI. The project is currently in the planning phase.

- Open a GitHub issue describing the proposed feature, bug or architecture decision before large changes.
- Include exact OS, CAD-engine, Python and ComfyUI versions with bug reports.
- For executable workflows, include the JSON file, required custom nodes and model references, plus evidence of a successful run.
- Submit pull requests that include tests, reproducible instructions, and documentation updates.
- Don't commit credentials, personal documents, model weights or generated assets with unclear rights.
- Engineering claims (ISO compliance, tolerances, watertightness) must be verifiable.
- Use short, descriptive commits; update the changelog and progress status for user-visible changes.

Governance and licensing will be refined before accepting substantial third-party code.
